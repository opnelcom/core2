# African Safaris tenant theme

Uses the existing standalone tenant CSS structure and theme variables. Burnt orange #b34b20 buttons, ivory #faf6ee backgrounds and dark warm text. The local generated safari asset is used by the shell, header and body; light overlays preserve readability.

Files: Volumes/Core-SaaS/public/themes/african-safaris.css and themes/assets/african-safaris-background.png. Registered in the Core-SaaS database initialisation theme list. Existing databases need an Administration theme entry named African Safaris with CSS file african-safaris.css, or the existing database initialisation/upsert process. Select it in tenant management after registration. Existing tenant selections are unchanged.

Image generated with the built-in image generation tool. Prompt: wide realistic African savanna panorama, acacia trees, distant elephants, dry grasses and layered hills; natural morning light, pale ivory sky, sandy background, burnt orange earth and muted olive foliage; calm negative space, middle horizon, suitable for a shallow header crop; no text, logos or watermark.
